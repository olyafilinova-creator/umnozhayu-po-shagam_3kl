# Умножаю по шагам

Интерактивный HTML-тренажёр для 3 класса по теме «Умножение двузначного числа на однозначное».

## Как открыть

1. Распакуйте архив, не изменяя расположение папок.
2. Дважды щёлкните по `index.html` — игра работает в браузере без интернета.
3. Выберите уровень сложности и число примеров (5, 10, 15 или 20).
4. Заполните пять полей и нажмите «Проверить».

## Как разместить на GitHub Pages

1. Создайте репозиторий на GitHub (или откройте существующий каталог игры).
2. Загрузите в корень репозитория `index.html`, папки `css` и `js`.
3. В репозитории откройте **Settings → Pages**.
4. В качестве источника выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и сохраните.
5. После развёртывания откройте ссылку, показанную GitHub Pages.

Если тренажёр хранится в отдельной папке уже опубликованного репозитория, файлы `index.html`, `css` и `js` должны находиться вместе внутри неё.

## Методика и проверка

* Число от 11 до 99 (с ненулевыми единицами) умножается на число от 2 до 9.
* Число разбивается **строго на разрядные слагаемые**: полные десятки и единицы.
* Затем отдельно вводятся два произведения и их сумма.
* Все пять окошек отображаются сразу; проверка выполняется **только по кнопке**.
* Ответы не превышают 150. Примеры в пределах одной тренировки не повторяются.
* Уровень 1: произведение единиц однозначное, общий ответ ≤100.
* Уровень 2: произведение единиц двузначное, общий ответ ≤100.
* Уровень 3: общий ответ от 101 до 150.
* Поля с ошибками выделяются. При исправлении правильные ответы остаются на месте.
* «Подсказка» открывает алгоритм из учебника (три шага) и наводящий вопрос к текущему примеру без готового ответа.
* Итоговая статистика: решение без ошибок и подсказок; после ошибок без подсказок; с подсказкой. Категории не пересекаются.

## Структура

- `index.html` — три экрана: выбор параметров, тренировка, итог.
- `css/style.css` — оформление и адаптивная вёрстка.
- `js/app.js` — генерация примеров и игровая логика.

Никаких внешних библиотек и сетевых запросов не используется.

## Оформление

Акцентный цвет морской волны `#27666B`, светлая бирюза `#E7F4F5`, графитовый текст. Цветовые переменные расположены в начале `css/style.css`.

## Проверка логики (26.11.2026)

Проверены 12 полных сценариев (3 уровня × 4 объёма), всего 150 примеров, а также пустой ввод, исправление неверного поля, применение подсказки, расчёт статистики и перезапуск. Исправлена подпись кнопки: повторное нажатие обновляет наводящий вопрос по текущим полям, но может повторить тот же вопрос, если ответы не изменены.
